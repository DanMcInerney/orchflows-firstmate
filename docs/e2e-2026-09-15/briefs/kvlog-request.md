Build kvlog, a Python 3 command-line tool that summarizes structured JSON-lines logs. Each input line is a JSON object with at least ts (ISO 8601), level (DEBUG, INFO, WARN, ERROR), service and msg; extra keys may exist and must not break parsing. kvlog reads one or more files or stdin and prints a summary: total lines, counts by level, counts by service, the top N most frequent ERROR messages with counts, and the covered time range. It must support --json for machine-readable output, --top N, --since and --until ISO 8601 filters, --help, exit code 0 on success, 1 on malformed input with the offending line number on stderr, and 2 on usage errors. Ship it with unit tests that run with python3 -m unittest, a README with install and usage examples, and no third-party dependencies.
