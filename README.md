# orchflows-firstmate

Private research workspace for making Orchflows easy to install, use, and upgrade alongside FirstMate.

**Start with [HANDOFF.md](HANDOFF.md).** It contains the next-session assignment and reading order. No memory of the original conversation is required.

The current hypothesis is to run selected Orchflows workflows inside normal FirstMate crewmates while FirstMate retains fleet supervision and delivery authority. This is a recommendation to investigate, not an approved design or a working integration.
