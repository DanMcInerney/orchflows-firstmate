**FirstMate/Herdr development package:** Read the [execution gate](docs/architecture.md#firstmate-execution-gate) before using a workflow. The client validates the actual controller, current caller generation and exact retained package attachment. Legacy single read-only Work or explicit-audit Review attachments keep their contract. Negotiated dynamic attachments support bounded Linux Work/join/Review composition, per-assignment controls and selected workflow call scopes. Only explicitly authorized Work callers may delegate scoped descendants through that client. Ship delivery requires negotiated ship-local-only capability and immutable delivery identity. FirstMate owns component execution, recovery and root delivery. [Build](skills/orch-build-workflow/SKILL.md) authors and trials complete libraries in the selected composition, then uses FirstMate-owned publication after ordinary delivery. Component continuation, general SelfImprove, direct-PR/no-mistakes delivery and promotion remain gated; there is no native fallback. Quoted upstream instructions and example libraries are migration source material. Package authoring and read-only/package CLI work remain permitted.
