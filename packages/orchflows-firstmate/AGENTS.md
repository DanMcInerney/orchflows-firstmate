**FirstMate/Herdr development package:** Read the [execution gate](docs/architecture.md#firstmate-execution-gate) before using a workflow. The client must validate the actual controller, current root generation and exact retained package attachment. Legacy single read-only Work or explicit-audit Review attachments retain their contract. Explicit dynamic attachments support bounded Linux Work/join/Review composition in a root scout or an explicitly selected ordinary ship/local-only root; ship delivery requires negotiated ship-local-only capability and immutable delivery identity. FirstMate owns component execution, recovery and root delivery. [Bounded leaf authoring](skills/orch-build-workflow/SKILL.md) uses the dynamic ship/local-only profile. General composing Build, SelfImprove, nesting, direct-PR/no-mistakes delivery and promotion remain gated; there is no native fallback. Quoted upstream instructions and example libraries are migration source material. Package authoring and read-only/package CLI work remain permitted.
