## Limits

This increment does not certify direct-PR/no-mistakes delivery, promotion,
nesting, Build/SelfImprove, broader optional examples, component continuation,
current Codex worker composition, full supervisor wake/drain/rearm or native
background-tool retirement. Native Windows remains deferred. Package readiness
stays package-only. No active installation, rotating credential cache, pinned
reference or historical receipt is changed; design-loop is not used.
